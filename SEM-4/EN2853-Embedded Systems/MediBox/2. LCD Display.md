### Code Analysis
#### Initialize The Display

> [!NOTE] `init_display()`
> 
> - This function initializes the OLED display.
> - It calls `display.begin()` to start the display with the specified parameters.
> - If the display initialization fails, it prints an error message to the serial monitor and enters an infinite loop.
> - If successful, it displays the initial screen content and waits for 100 milliseconds.

```cpp
void init_display()
{
    if (!display.begin(SSD1306_SWITCHCAPVCC, SCREEN_ADDRESS))
    {
        Serial.println(F("SSD1306 allocation failed"));
        for (;;)
            ;
    }
    display.display();
    delay(100);
}
```

#### Print a Line

> [!NOTE] `print_line(String text, int column, int row, int text_size)`
> 
> - This function prints a line of text on the display at a specified position and size.
> - Parameters:
>     - `text`: The text to be displayed.
>     - `column`: The x-coordinate (horizontal position) on the display.
>     - `row`: The y-coordinate (vertical position) on the display.
>     - `text_size`: The size of the text.
> - It sets the text size and color, positions the cursor, prints the text, and updates the display.

```cpp
void print_line(String text, int column, int row, int text_size)
{
    display.setTextSize(text_size);
    display.setTextColor(SSD1306_WHITE);
    display.setCursor(column, row);
    display.println(text);
    display.display();
}
```

#### Display Current Time

> [!NOTE] `print_time_now()`
> 
> - This function displays the current time on the OLED display.
> - It first clears the display.
> - It then prints the current time in the format `days:hours:minutes:seconds` at specified positions on the display.
> - It waits for 800 milliseconds before the function ends.
> - **Note:** The variables `days`, `hours`, `minutes`, and `seconds` are defined elsewhere in the code.

```cpp
void print_time_now(void)
{
    clear_display();
    print_line(String(days), 0, 0, 2);
    print_line(":", 20, 0, 2);
    print_line(String(hours), 30, 0, 2);
    print_line(":", 50, 0, 2);
    print_line(String(minutes), 60, 0, 2);
    print_line(":", 80, 0, 2);
    print_line(String(seconds), 90, 0, 2);
    delay(800);
}
```
