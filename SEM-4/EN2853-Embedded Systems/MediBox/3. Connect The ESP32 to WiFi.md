## Objective

- Connect the ESP32 to WiFi

> [!info] Required Functions
> - Initialize the Wifi connection : `init_wifi()`

## Code


> [!warning] The code provided is for connecting the ESP32 to a Wi-Fi network using the `<WiFi.h>` library.


### Wi-Fi initialization code

```cpp
#include "wifi_manager.h"
#include "display.h"
#include <WiFi.h>

const char *default_ssid = "Wokwi-GUEST";
const char *default_password = "";
int channel = 6;

void init_wifi()
{
    WiFi.begin(default_ssid, default_password, channel);
    while (WiFi.status() != WL_CONNECTED)
    {
        clear_display();
        print_line("Connecting to WIFI", 0, 0, 2);
        delay(250);
    }
    clear_display();
    print_line("Connected to WIFI", 0, 0, 2);
    delay(500);
    clear_display();
}

```
