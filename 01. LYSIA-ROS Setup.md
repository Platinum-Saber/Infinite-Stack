
> [!info] Pre-Requisites 
> - install **ROS2-Jazzy** 
>- Refer [Ubuntu installation guide for ROS](https://docs.ros.org/en/jazzy/Installation/Alternatives/Ubuntu-Development-Setup.html)

> [!NOTE] 1- Create a ROS Workspace
> ```cmd
> mkdir lysia_ws
> cd lysia_ws
> mkdir src
> ```

> [!NOTE] 2- Clone the template
> ```cmd
> cd src/
> git clone https://github.com/Platinum-Saber/lysia-prototype.git
> ```

> [!NOTE] 3- Build ROS Package
> ```cmd
> colcon build --symlink-install
> ```
> `symlink` allows for dynamic package building
>> [!warning] `symlink` only supports `Python` language
