In **Obsidian**, you can use **MathJax** to write arrows inside LaTeX math blocks (`$...$` for inline and `$$...$$` for block display).

| Arrow Type        | MathJax Code      | Rendered Symbol |
| ----------------- | ----------------- | --------------- |
| Right arrow       | `\rightarrow`     | →               |
| Left arrow        | `\leftarrow`      | ←               |
| Up arrow          | `\uparrow`        | ↑               |
| Down arrow        | `\downarrow`      | ↓               |
| Double right      | `\Rightarrow`     | ⇒               |
| Double left       | `\Leftarrow`      | ⇐               |
| Long right        | `\longrightarrow` | ⟶               |
| Long left         | `\longleftarrow`  | ⟵               |
| Double long right | `\Longrightarrow` | ⟹               |
| Double long left  | `\Longleftarrow`  | ⟸               |
